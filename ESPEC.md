# ESTUDIANTE — IA para hacer mejores estudiantes (spec v1, Omar 12-oct)
PRINCIPIO: en vez de IA para memes, IA para estudiar. Gente comun con
capacidades reducidas: todo se OYE, nada se lee.

1. Se instala -> detecta idioma del sistema operativo.
2. Estudiante elige materias -> descarga PDFs necesarios (fuentes
   abiertas: CONALITEG libros gratis MX, OpenStax, wikilibros).
3. PDF -> texto -> idioma preferido del estudiante -> VOZ por capitulo.
4. Boton ELEGIR CAPITULOS. Botones redondeados, colores suaves que
   permitan INTUIR que hace cada uno (misma escuela que Radio Zi).
5. IDIOMAS: el del sistema al instalar + cambiar entre los 10
   principales del mundo. Diccionarios de lenguas con +100 mil
   hablantes: se descargan aparte, hospedados por nosotros.
6. LENGUAS ANCESTRALES: nahua, maya y hasta ~50 antiguas del mundo,
   cada una con breve descripcion de su COSMOVISION (ejemplo canonico:
   el "no" nahua). Solo disponibles al descargar. Teclados con glifos
   propios cuando existan.
7. INVITACION a colaborar en GitHub para ampliar lenguas.
8. MODO DISCAPACIDAD: esquina azul con logo de accesibilidad
   ("somos iguales") en la barra, como en Radio Zi.

FODA (regla Omar):
F: reusa Radio Zi + lee_pdf + piper (ya viven); costo $0; 100% local.
D: catalogo de materias requiere curaduria; glifos antiguos escasos en fuentes.
O: NLnet; CONALITEG como catalogo inicial; comunidad GitHub para lenguas.
A: enlaces muertos; licencias (solo libros abiertos); candados de nube.
FASES: F1 capitulos+radio (hoy) | F2 catalogo materias | F3 diccionarios+
ancestrales | F4 teclados glifos | F5 ordenes por voz (Vosk es, pendiente).
